`Next.js` · `Supabase` · `Vercel`

### [Filtro de Partículas](https://github.com/RichardBrendon/Particle-Filter)

Projeto acadêmico de estimativa de posição. Adaptei o algoritmo em C às limitações de memória de uma placa STM32 e usei Python e comunicação serial para comparar os resultados com a implementação de referência.

`C` · `Python` · `STM32F030R8` · `UART`
